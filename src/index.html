Taildesk 0.1.0

An independent Windows companion for your existing Tailscale installation.

View devices, copy addresses, check reachability, reconnect, choose an exit node, and manage common connection settings.

Tailscale provides authentication, encryption, and networking. Taildesk is not affiliated with or endorsed by Tailscale. This is a functional recreation of common client controls, not a pixel-identical copy.

Sign-in, account switching, file transfers, and advanced administration remain in the official Tailscale app. Closing this window keeps Taildesk in the system tray. Quitting Taildesk does not disconnect Tailscale.
